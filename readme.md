# Salong Nina – webbplats för frisörsalong

Webbplats för den fiktiva frisörsalongen **Salong Nina**, skapad som projektuppgift i kursen DT224G. Målgruppen är personer som vill boka klippning, hårfärgning eller styling, och webbplatsen låter besökaren se salongens tjänster, läsa vanliga frågor, kontakta salongen och skicka en bokningsförfrågan.

🌐 **Publicerad webbplats:** https://maariaamm.github.io/Hairstylist/

**Link to my Figma design:** https://www.figma.com/design/Lz3YiwRzp5yd7c3Hcmr4hz/Hairstylist?node-id=0-1&t=XDYWppLim8lUOHjT-1

### Skriftlig rapport - [Projektrapport (PDF)](projektuppgift-SalongNina.pdf)

## Sidor

- **Startsida** (`index.html`) – presentation av salongen, tjänster, omdömen, öppettider och adress
- **Tidsbokning** (`booking.html`) – formulär för bokningsförfrågan
- **FAQ** (`faq.html`) – vanliga frågor och svar
- **Kontakt** (`contact.html`) – kontaktuppgifter och kontaktformulär

## Teknik

- HTML, CSS och JavaScript utan ramverk
- Mobile first-design med Flexbox, CSS Grid och media query

## JavaScript-funktionalitet

- Mobilmeny som öppnas och stängs
- Validering av bokningsformuläret och kontaktformuläret med tydliga felmeddelanden
- Visning av om salongen har öppet eller stängt just nu
- Bokningsförfrågan sparas i `localStorage`

## Bildkällor

Samtliga bilder som använts på webbsidan är från Pexels.
